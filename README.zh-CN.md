# PaperPeek

[English](README.md) | **简体中文**

在浏览器里读论文 PDF：双页阅读 + 悬停预览引用、图、表、公式。基于 pdf.js，没有构建步骤。

## 用法一：本地网页版

```bash
node server.mjs
```

打开 <http://localhost:8177/>，然后任选一种方式打开 PDF：

- 把 PDF 文件拖进窗口，或点「打开文件」
- 在地址框里粘贴 PDF 链接、arXiv 页面地址或 arXiv 编号（如 `1706.03762`），回车

需要 Node 18 以上。`server.mjs` 只监听本机（127.0.0.1），除了提供静态文件，还带一个转发接口：
遇到不允许跨域读取的站点时，由它代为下载 PDF（arXiv 本身允许跨域，不走转发）。

## 用法二：Chrome / Edge 插件

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），开启「开发者模式」
2. 点「加载已解压的扩展程序」，选择本仓库的文件夹（`git clone` 下来的，或下载 ZIP 解压后的）
3. 想接管本地 PDF（`file://`）：在插件的「详情」里打开「允许访问文件网址」

之后浏览器里打开任何 PDF 都会自动转到 PaperPeek。点工具栏上的插件图标可以暂停 / 恢复接管
（暂停时图标显示 OFF）。在查看器里按浏览器的「后退」会回到浏览器自带的 PDF 视图，再退一步离开。

## 功能

| 功能 | 操作 |
| --- | --- |
| 单页 / 双页 / 双页且封面单独 | 工具栏中间的三个按钮 |
| 悬停预览 | 鼠标停在引用编号、「图 3」「公式 (2)」「第 4 节」、脚注标记等内部链接上 |
| 跳转 | 点击链接，或点击弹窗里的预览图；参考文献 / 公式 / 脚注跳过去后会闪一下高亮 |
| 返回原位置 | 底部的「返回原位置」按钮，或 `Alt + ←`、`Backspace`（可连续返回多级） |
| 缩放 | 工具栏的 − / + / 下拉框，`Ctrl/⌘ + 滚轮`（触控板捏合），`Ctrl/⌘ + +/−/0` |
| 目录 | 左上角 ☰（来自 PDF 书签） |
| 下载 PDF | 工具栏放大镜右边的 ↓ 按钮，或 `Ctrl/⌘ + S`（存的是 PDF 本身，不重新下载） |
| 页内搜索 | `Ctrl/⌘ + F`，回车下一个，`Shift + 回车`上一个，`Esc` 关闭 |
| 翻页 | `←` / `→`（双页模式下一次翻一个跨页），或在页码框输入页码 |
| 界面语言 | 工具栏最右边的下拉框：中文 / English |

布局、缩放和语言的选择会记住（全局，不分文件）。没选过语言时跟随浏览器：首选语言列表里有中文就用中文，否则用英文。
插件在扩展管理页里显示的名称和简介跟随浏览器自身的界面语言，不受这个下拉框影响。

### 预览是怎么取的

只依赖 PDF 自带的内部链接，不做文字识别：

- **参考文献**：从目的地开始，到同一栏里下一条参考文献的目的地为止，正好裁出一条。
- **图 / 表**：在目标页找到对应的图注（`Figure 3:` / `Table 2.`），再判断图表在图注上方还是下方。
- **公式**：在目的地附近找到 `(N)` 编号，围绕它取一块。
- **章节、脚注、其他**：从目的地往下取一段。

分栏靠文字在水平方向的投影自动判断（只看目标附近，所以半页通栏、半页双栏也能处理）。
渲染后会裁掉上下的空白和被切了一半的相邻行。

## 已知限制

- 没有内部链接的 PDF（扫描件、部分早期论文）没有悬停预览——这是有意不做的范围。
- 一条参考文献跨栏或跨页时，只显示前半段。
- 特别高的图（占满一整栏）在弹窗里可能要滚动才能看全。
- 插件在 Edge（Chromium 157）里实测过；Chrome 用的是同一套扩展接口，但还没有在 Chrome 里实测。
